# S-29453A SPI EEPROM Driver & Memory Programmer

An Arduino-based SPI driver, memory programmer, and hexadecimal dumper for the **Seiko Instruments S-29453A** serial CMOS EEPROM.

---

## 📌 Overview

The **S-29453A** is an 8,192-bit ($512 \times 16$-bit) serial non-volatile EEPROM communicating via a specialized 3-wire/4-wire SPI protocol. This project provides complete Arduino utilities to read the entire memory space into structured hexadecimal/word dumps and program arbitrary 16-bit data words with hardware write-protection handling.

---

## ⚙️ Chip Specifications

| Parameter | Value |
| :--- | :--- |
| **Capacity** | 8,192 bits (8 Kbit / 1 KByte) |
| **Memory Organization** | 512 words $\times$ 16 bits |
| **Interface** | SPI (Mode 0: CPOL=0, CPHA=0, MSB First) |
| **Operating Frequency** | Standard SPI clocking with prescalers (`SPI_CLOCK_DIV64`) |
| **Instruction Set** | Read, Write, Write Enable (WEN), Write Disable (WDS) |
| **Address Space** | `0x000` to `0x1FF` (9-bit address) |

Connect the S-29453A EEPROM to the Arduino as shown below:

| Arduino Pin | S-29453A Pin | Function / Description |
| :--- | :--- | :--- |
| **Pin 7** | `/CS` (Chip Select) | Active-Low / High Chip Select |
| **Pin 13 (SCK)** | `SK` (Serial Clock) | SPI Clock generated by Arduino |
| **Pin 11 (MOSI)**| `DI` (Data In) | Serial command & data input |

| **Pin 8** | Status LED | Visual indicator during active write cycles |
| **5V / 3.3V** | `VCC` | Power supply |
| **GND** | `GND` | Common Ground |

## 📖 Protocol & Instructions

Communication frames consist of instruction opcodes concatenated with the 9-bit word address:

1. **Write Enable (WEN)**:
   Sends opcode `0b10100000 | 0b11` to unlock the memory array for write operations.
2. **Write Disable (WDS)**:
   Sends opcode `0b10100000 | 0b00` to protect memory from accidental overwrite.
3. **Read Memory (READ)**:
   - Command frame: `(0b1010100 << 9) | Address (A8..A0)`
   - Clock out: 16 data bits ($D_{15} \dots D_0$).
4. **Write Memory (WRITE)**:
   - Command frame: `(0b1010010 << 9) | Address (A8..A0)`
   - Clock in: 16 data bits ($D_{15} \dots D_0$).
   - Chip select toggling and internal write cycle delay ($t_{PR} \approx 6\text{–}20\text{ms}$).

## 🚀 How to Use

### 1. Dumping Memory (`Read_512X16_MSBF_E.ino`)
1. Open `Read_512X16_MSBF_E.ino` in the Arduino IDE.
2. Select your Arduino board (e.g. Arduino Uno / Nano) and COM port.
3. Upload the sketch and open the **Serial Monitor** at **9600 baud**.
4. Pull **Pin 5 HIGH** (or press the trigger button).
5. The memory contents will be printed as a formatted 16-bit hex table:
   ```text
   0x0000 : 00A5 0000 0000 0003 0000 0000 0000 0FEC
   0x0008 : 246F 0019 4FB4 0001 0001 000A 0007 0006
   ...
   ```

### 2. Programming Memory (`Write_512X16.ino`)
1. Define your payload array in `Write_512X16.ino` (`DATA[512]`).
2. Upload the sketch to the Arduino.
3. Pull **Pin 5 HIGH** to start flashing.
4. Pin 8 LED will light up during the write sequence and turn off upon completion.
